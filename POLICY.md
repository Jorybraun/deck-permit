# Offline non-selection engineering test

This is a fictional-role engineering test using owner-selected public
source. It is not approved production legal terms, an interview
admission grant, a candidate consent receipt or permission to contact applicants.

- Network: denied during validation and exercise execution. Dependencies are
  installed only while building the separately pinned runtime image. The exercise
  requires no API access, delivery, municipal lookup or account sign-in.
- Tools: pinned Node.js and the lockfile's TypeScript/Vitest/Vite dependencies,
  Git, terminal and editor. No new package installation or tool downloads.
  AI use is prohibited for the exercise; no model access or credentials are supplied.
- Capture: none. No candidate camera, microphone, recording or transcript.
- Workspace: src, tests and reports are writable. Reports are generated output
  excluded from submitted work. Dependencies and policy/configuration files are
  read-only during validation. Local containers do not establish production
  durability or isolation guarantees.
- Time: untimed non-selection engineering demonstration, not an accommodation
  decision or a timed assessment.
- Source rights: the repository owner selected this public repository for this
  adaptation and test. No new third-party license, ownership claim or permission
  to redistribute third-party dependencies is granted by this file. Existing
  dependency license notices remain in the runtime. Private assessment material,
  credentials and candidate information must never be included in public source
  or runtime image layers.
- Work terms: no real applicant work or transfer of candidate IP is requested.
  No ranking, score, hiring recommendation or selection-validity claim is made.
  A real release requires separately reviewed terms and actual participant consent.

A manifest pin binds these exact bytes; it does not prove the runtime enforces
them. PIPEY must separately support and verify this policy and runtime before
